## 🎯 Yang Dipelajari
- @keyframes untuk animasi CSS
- animation shorthand & animation-delay
- transform: rotate, scale
- box-shadow untuk efek pulse
- :nth-child selector
- Gradient + background-position untuk shimmer
- CSS Grid dengan grid-column: span
